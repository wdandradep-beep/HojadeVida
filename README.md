# Interactive Resume Website

Currículum vitae desarrollado como una página web responsive utilizando HTML y CSS, diseñado para presentar de manera profesional información académica, experiencia laboral, habilidades técnicas y proyectos personales.

El proyecto fue creado con un enfoque moderno y minimalista, priorizando la legibilidad, la experiencia de usuario y una presentación visual alineada con perfiles tecnológicos y entornos SaaS.

---

## Objetivo del Proyecto

Diseñar y desarrollar una versión web de un currículum profesional aplicando principios de:

- Diseño responsivo
- Jerarquía visual
- Organización de información
- Experiencia de usuario (UX)
- Desarrollo Frontend

---

## Características

✅ Diseño responsive

✅ Sidebar informativo

✅ Presentación profesional de experiencia laboral

✅ Sección de proyectos tecnológicos

✅ Integración de imágenes y previews de proyectos

✅ Organización visual enfocada en reclutadores

✅ Estructura HTML semántica
